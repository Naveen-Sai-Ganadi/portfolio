## Selection and interpretation

Repository metadata for all nineteen entries is stored in `src/github-index.json`. `Pycharm`, `Git-example`, and `automation` were empty in the snapshot. `VacayGuide` is marked as a fork. The companion Slashh repositories, notebook/ML projects, and portfolio repository remain directly accessible in the catalog without implying undocumented capabilities.

The project code was not executed or independently audited. The animations communicate documented workflows using procedural geometry; they do not claim benchmark results, deployment status, customer traction, medical validity, or ownership of every contribution. Team-project attribution is retained for the voice project. Synthetic face-shaped geometry is used for the vision illustrations and contains no biometric analysis of the supplied portrait.

No live GitHub API calls are made by the deployed site. To refresh the catalog, review public changes and update `src/github-index.json` and the review date in `src/github-section.js`.
